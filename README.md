# 🐧 Rafael Monteiro

**`Desenvolvedor Python | Entusiasta Linux & Shell | Automação com Inteligência Artificial`**

Olá! Me chamo Rafael Monteiro e sou desenvolvedor focado em **Python**, automação de sistemas para **Linux** e integração de modelos de IA. 

Gosto de transformar o terminal em um ambiente inteligente de alta produtividade. Sou o criador do ecossistema [**Metis**](https://github.com/faelmonteiro/Metis), unindo modelos locais offline (Ollama) e nuvens de alta velocidade para criar agentes autônomos, visão computacional de tela e copilotos inteligentes diretamente no shell.
